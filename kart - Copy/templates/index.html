How It Works

01

Open Your Webcam

Flask opens cv2.VideoCapture(0) server-side and runs MediaPipe at 0.6× zoom-out — same as the original Qt app — to give more body room in frame.

02

Angle-Based Scoring

similarity_score() from core/pose_matcher.py computes 11 joint angles (elbows, hips, knees, torso) and scores each against the reference — same algorithm PoseCanvas uses.

03

Live Feedback

Score is smoothed over 5 frames (deque). At ≥ threshold you pass; at ≥ 80% of threshold you get "Close"; below that — "Try again". The reference animation plays alongside.

      Capabilities

      Built for Precision

      Angle-Based Matching

      similarity_score() in core/pose_matcher.py computes 11 key joint angles (elbows, shoulders, hips, knees) and scores each within a ±60° tolerance window. Weighted average → 0–100 score.

      5-Frame Score Smoothing

      Scores are averaged over a deque(maxlen=5) — identical to PoseCanvas — so jitter from individual frames doesn't cause false passes or failures.

      Reference Animation Panel

      Each level's animation field (3 captured skeleton frames) is drawn in the side panel — the same reference skeleton PoseCanvas showed next to the camera feed.

      WebSocket Live Stream

      Annotated OpenCV frames sent as base64 JPEG over WebSocket at ~20fps. The backend applies the same 0.6× zoom-out PoseCanvas uses before feeding to MediaPipe.
